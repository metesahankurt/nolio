# Nolio — brand kit

The mark is drawn from the name: one leaf of paper folded into an N, its turned corner sealed.
Source of truth: `icon/icon-brand.svg` (1024 app-icon composition). Accent: `#E0A526`.

| File | Use |
|---|---|
| `icon/icon-brand.svg`, `icon/icon-brand-1024.png` | App icon as drawn |
| `icon/icon-dark.svg` / `icon/icon-light.svg` | Same tile with a hairline edge for dark / light backgrounds |
| `icon/macos/icon-*-1024.png` | Apple icon grid (824 body, 100 px margin, shadow) |
| `icon/mark.svg`, `icon/glyph-1024.png` | The mark alone on transparency |
| `favicon/` | `favicon.svg` (adapts to light/dark browser chrome), `favicon.ico` 16–256, apple-touch, PWA 192/512 + maskable |
| `logo/logo-{light,dark}.{svg,png}` | Horizontal lockup; `light` is for light backgrounds |
| `social/og-{dark,light}.png` | 1200×630 share cards; the dark one is wired into the site |

Headline: “Encrypted notes that stay on your device.”
